# 🏠 House Price Prediction System

A Machine Learning project that predicts house prices based on house features such as area, number of bedrooms, and age of the house.

---

## 📌 Project Overview

The House Price Prediction System uses the **Linear Regression** algorithm to estimate the price of a house. The model is trained using historical housing data and can predict prices for new houses based on user inputs.

This project demonstrates the basic concepts of:

- Data Preprocessing
- Machine Learning
- Linear Regression
- Model Training
- Price Prediction
